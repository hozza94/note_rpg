# 📘 Basileia 구현 계획서 #4: 전투 확장 및 진행 콘텐츠 고도화

## 목표
- 스킬 데이터(`GAME_DATA.skills`)를 실제 전투 로직과 연결한다.
- 지역 확장/상점 루프/골드 소비 구조를 추가해 진행 동기를 강화한다.
- 계정 저장 기반 위에 백업 업로드/복원 인터페이스를 도입한다.

## 반영된 항목
1. 전투·스킬 정합
   - 플레이어 스킬(`묵상`, `찬양`, `선포`)이 데이터 기반으로 동작하도록 수정.
   - 몬스터가 확률적으로 보유 스킬을 사용하도록 변경.
   - 공포/둔화/회피/방어 버프를 턴 단위 상태효과로 관리.
   - 도주 확률을 속도 기반 공식으로 변경.

2. 스탯·문서 정합
   - 현재 구현 기준(atk/def/spd/faith + HP/PP)으로 `Docs/specs/features.md`를 갱신.
   - 전투 규칙과 성장 규칙을 실제 코드 기준으로 일치시킴.

3. 콘텐츠 확장
   - 신규 지역 `hidekel`과 몬스터/보스/드롭 테이블 추가.
   - 지역별 상점(`GAME_DATA.shops`) 도입 및 상점 구매 UI/로직 추가.
   - 장비 슬롯 확장(helmet/accessory/offhand 아이템군 추가).

4. 백업/동기화 기반
   - `StorageManager`에 백업 업로드/복원 API 추가.
   - 설정 모달에서 백업 버튼으로 즉시 업로드/복원 가능하도록 연동.

5. 전투 연출 보강
   - 보스 저체력 컷신 로그.
   - 전투 상태 칩(버프/디버프) UI 표시.

## 검증 체크리스트
- [ ] 일반 몬스터/보스 전투에서 스킬 사용 로그가 표시되는가
- [ ] 공포 상태에서 행동 불가가 발생하는가
- [ ] 찬양(회피)와 묵상(수호/치명) 버프가 정상 만료되는가
- [ ] 도주 확률이 속도 차이에 따라 체감적으로 달라지는가
- [ ] 상점 구매 시 골드 차감 + 아이템 지급이 정상 동작하는가
- [ ] 백업 업로드 후 복원 시 상태가 복원되는가
