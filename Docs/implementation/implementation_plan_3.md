# 📖 Basileia 구현 계획서 #3: UI & FX 시각 강화

본 계획서는 게임의 몰입감을 높이기 위한 전투 연출 고도화 및 시스템 이벤트 시각화 방안을 담고 있습니다.

## 🎯 목표
1.  **전투 타격감 개선**: 데미지 팝업과 치명타 전용 FX를 통해 리드미컬한 전투 피드백 제공.
2.  **이벤트 연출 강화**: 예배(Worship) 시 성경 구절이 품격 있는 카드 형태로 노출되도록 개선.
3.  **시각적 완성도**: 화면 흔들림 및 피격 효과를 정교화하여 게임의 톤앤매너 완성.

## ⚔️ 사용자 리뷰 필요 사항 (User Review Required)

> [!IMPORTANT]
> 1. **팝업 자동 제거**: 데미지 팝업은 약 1~1.5초 후 자동으로 DOM에서 제거되도록 설계하여 성능을 최적화합니다.
> 2. **모달 정렬**: 성경 구절 카드는 화면 정중앙에 나타나며, 일정 시간 후 자동으로 닫히거나 클릭 시 닫히는 선택지를 검토합니다. (현재는 자동 닫힘 + 클릭 병행 예정)
> 3. **치명타 색상**: 일반 데미지(흰색/회색)와 치명타(빨간색/금색)를 확실히 구분하여 시각적 쾌감을 제공하겠습니다.
