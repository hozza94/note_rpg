# 구현 계획 7: 스킬트리 선택·해금 분리 및 토스트 UX

## 목표
1. 노드 **첫 클릭 = 선택**, **「배우기」 버튼**으로만 `unlockSkillNode` 호출.
2. 토스트 스택을 확대/축소 툴바와 겹치지 않도록 **문서 흐름(뷰포트 아래)** 배치.
3. 토스트 메시지 앞에 **이모지 프리픽스**로 종류 구분.

## 변경 파일
- `game.js`: `openSkillTreeModal` 선택 상태·배우기 버튼·`showSkillTreeToast` 이모지.
- `style.css`: `.skill-web-toast-stack` 위치, `.skill-web-learn-row`, `.is-selected` 링 강조.

## 검증
- [ ] 노드 클릭만으로는 해금되지 않는다.
- [ ] 배우기로만 포인트가 소모되고 그래프/탭이 갱신된다.
- [ ] 토스트가 줌 컨트롤을 가리지 않는다.
- [ ] 성공/실패 토스트에 이모지가 붙는다.
