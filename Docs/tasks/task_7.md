# task_7: 데이터 백업 슬롯화 작업

## 목적
- 백업/복원 안전성을 높이기 위해 단일 백업 구조를 3슬롯 구조로 확장한다.

## 체크리스트
- [x] `StorageManager` 슬롯 키 생성 메서드 추가 (`getCloudSlotKey`)
- [x] 슬롯 업로드 메서드 추가 (`syncToCloudSlot`)
- [x] 슬롯 복원 메서드 추가 (`restoreFromCloudSlot`)
- [x] 슬롯 목록 조회 메서드 추가 (`listCloudBackups`)
- [x] 기존 `syncToCloud`/`restoreFromCloud` 하위호환 유지 (슬롯 1 위임)
- [x] `game.js` 백업 버튼 동작에 슬롯 선택 prompt 연결
- [ ] 수동 점검: 슬롯 1/2/3 각각 업로드 후 목록 라벨 시간 확인
- [ ] 수동 점검: 슬롯별 복원 정확성 확인 (레벨/골드/인벤토리)
- [ ] 수동 점검: 빈 슬롯 복원 시 오류 메시지 확인

## 검증 시나리오
1. 설정 > 백업 업로드 클릭
2. 슬롯 2 선택 후 업로드
3. 게임 상태 일부 변경
4. 설정 > 백업 복원 클릭, 슬롯 2 선택
5. 업로드 시점 상태로 정상 복원되는지 확인
