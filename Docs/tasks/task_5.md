## 검증 시나리오
1. 탐험 화면에서 `🔨 대장간` 버튼 클릭 시 모달이 정상 노출된다.
2. `강화` 탭에서 재화 부족 시 경고 토스트가 표시된다.
3. `분해` 탭에서 장비 분해 시 골드/재료가 즉시 반영된다.
4. `제작` 탭에서 레시피 제작 후 인벤토리 반영 및 로그가 출력된다.
