# Task 10 - 배포/로그 설계 실행 태스크

본 문서는 `Docs/plans/deploy_plan_1.md`, `Docs/plans/logging_plan_1.md`를 실제 구현 단위로 분해한 실행 태스크 목록이다.

---

## 1) 목적

- 배포 전 필수 기반(저장/인증/관측성/운영 안전장치)을 우선 구축한다.
- 전투/경제/시설 이벤트를 요약 로그 중심으로 기록해 운영 가능한 상태를 만든다.

---

## 2) 작업 범위

- 서버 저장 구조, 인증, 마이그레이션
- 공통 로거 및 이벤트 로깅
- 모니터링/알람/감사 로그
- 스테이징 검증 및 배포 파이프라인

---

---

## 5) 구현 규칙

- 이벤트 이름 규칙: `<domain>.<action>.<result>`
  - 예: `battle.completed.success`, `economy.currency.changed`
- 재화 관련 이벤트는 `delta/before/after/reason` 필수
- 전투는 요약 로그 우선, 턴별 상세는 샘플링만 허용
- 민감정보(비밀번호/토큰 원문) 로그 저장 금지

---

## 6) 수용 기준 (Definition of Done)

- [ ] P0 작업 완료 후 스테이징에서 저장/로드/로그인 정상 동작
- [ ] 로그 검색으로 특정 유저의 전투/재화 흐름 추적 가능
- [ ] 재화 이상치 알람 1종 이상 실제 트리거 검증
- [ ] 마이그레이션 실패 시 롤백/복구 절차 문서화

---

## 7) 리스크 및 완화

- 로그 과다 적재로 비용 증가
  - 완화: 요약 로그 중심, 상세 샘플링, 보관기간 정책
- 이벤트 스키마 불일치
  - 완화: 공통 로거 + 스키마 검증 테스트
- 운영자 도구 오용
  - 완화: 감사 로그 + 권한 분리 + 승인 절차
