# 📘 Basileia 구현 계획서 #5: 스킬트리(PoE 참고) 1차 도입

## 목표
- 직업 고정형(순례자) 기반으로 연결형 스킬트리를 도입한다.
- 전투 액티브 스킬과 상시 패시브 효과를 분리해 표현/적용한다.
- 스킬트리 모달에서 노드 해금, 포인트 소모, 저장을 일관되게 제공한다.

## 반영 범위

### 1) 데이터/스키마
- `GAME_DATA.skillTrees.pilgrim` 추가
  - 클러스터, 노드, 엣지, 시작 노드 정의
  - `active_unlock` 노드로 신규 액티브 스킬 해금
- 플레이어 상태 확장
  - `classId`
  - `activeSkillIds`
  - `unlockedSkillNodes`
  - `skillTreePoints`

### 2) 스킬트리 모달
- 스킬탭/설정에서 진입 가능
- 노드별 상태(해금됨/해금 가능/잠김) 표시
- 연결 조건 + 포인트 조건 검증 후 해금

### 3) 우측 스킬 탭 분리
- 액티브 스킬 목록: 전투에서 선택 가능한 스킬
- 패시브 스킬 목록: 트리에서 해금된 상시 노드

### 4) 전투/스탯 연동
- 패시브 보너스를 스탯 계산에 합산
- 전투 시 치명타, 회피, 피해량/피해감소, 저체력 배율 반영
- 레벨업 시 스킬트리 포인트 추가 지급

## 검증 체크리스트
- [ ] 스킬트리 포인트가 0일 때 노드 해금이 차단되는가
- [ ] 인접 노드가 아닌 경우 해금이 거부되는가
- [ ] `active_unlock` 노드 해금 후 전투 스킬 메뉴에 즉시 나타나는가
- [ ] 패시브 노드 해금 전/후로 스탯(HP/PP/ATK/DEF 등) 표기가 달라지는가
- [ ] 패시브 효과가 전투 피해량/회피율에 체감 반영되는가
