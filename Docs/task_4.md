# Task 4: 아이템 풀 확장 + 대장간 MVP 구현

## 목표
- 아이템 풀 1차 확장(신규 재료/장비/레시피) 적용
- 대장간 MVP(강화/분해/제작) 구현
- 저장 호환을 유지하며 실제 플레이 루프에 연결

## 확정된 정책
- 강화 실패 시: **단계 유지**
- 강화 상한: **+10**
- 고강화 표시: **색상/광휘 효과 적용**

## 작업 항목
- [ ] `GAME_DATA`에 대장간 설정(`smithing`) 추가
  - [ ] 강화 확률/계수/최대 단계(+5) 정의
  - [ ] 제작 레시피 테이블 정의
  - [ ] 분해 보상 테이블 정의
- [ ] 아이템 풀 1차 확장
  - [ ] 신규 재료 3종 추가
  - [ ] 신규 장비 8~12종 추가
  - [ ] 일부 드랍/상점 라인업 확장
- [ ] 상태 스키마 확장
  - [ ] `player.smithLevel` 기본값 추가
  - [ ] `player.itemEnhance` 맵 기본값 추가
- [ ] 대장간 UI/동작
  - [ ] 하단 액션에 `🔨 대장간` 버튼 추가
  - [ ] 모달 탭(강화/분해/제작) 렌더링
  - [ ] 강화 실행(골드/재료 차감, 확률 판정, 단계 상승)
  - [ ] 분해 실행(장비 1개 소모, 재료/골드 환급)
  - [ ] 제작 실행(재료/골드 소모, 장비 지급)
- [ ] 스탯 반영 연결
  - [ ] 장착 장비의 강화 단계가 실제 스탯에 반영되도록 계산 경로 확장
  - [ ] 인벤토리/장비 패널에 `+강화 단계` 표기
- [ ] 문서 업데이트
  - [ ] `Docs/features.md`에 대장간/강화 규칙 반영

## 구현 메모
- 1차는 인벤토리 인스턴스화 없이 **아이템 ID 단위 강화**로 진행
  - 같은 ID 장비는 동일 강화 단계 공유
  - 저장/호환 리스크를 낮추고 기능을 빠르게 검증
- 인스턴스 장비 분리는 Task 5에서 진행
- Task 4 범위에서는 인스턴스 전환을 수행하지 않음(명시적 연기)

## 완료 기준
- 플레이어가 대장간에서 강화/분해/제작을 실제로 수행 가능
- 강화 수치가 전투 및 UI 스탯에 즉시 반영
- 저장 후 재접속 시 강화 정보 유지
