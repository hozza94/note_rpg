# ⚙️ Basileia 게임 시스템 상세 정의 (Features)

본 문서는 현재 구현 기준(v2)으로 정리된 핵심 수치와 시스템 규칙입니다.

## 1. 캐릭터 스탯 및 성장

### 1.1 기본 스탯

| 스탯 | 설명 |
| :--- | :--- |
| **ATK** | 물리/공격형 스킬의 기본 위력 |
| **DEF** | 받는 피해 감소 |
| **SPD** | 선공 판정 및 도주 확률에 영향 |
| **FAITH** | 신앙 보너스 피해 및 일부 장비 시너지 |
| **HP / PP** | 생존 자원 / 스킬 자원 |

### 1.2 성장 시스템
- **경험치 UI**: 현재 보유 EXP / 다음 레벨까지 필요 EXP가 좌측 패널 바로 표시됩니다.
- **경험치 요구치**: 현재 `nextExp = floor(nextExp * 1.5)` 방식.
- **레벨업 보상**:
  - `maxHp +12`, `maxPp +4`, `atk +2`, `def +1`, `spd +2`
  - 보너스 포인트 `+2`
  - 스킬트리 포인트 `+1`
  - HP/PP 전량 회복
- **보너스 포인트 투자**:
  - 공격 +2 / 방어 +1 / 신앙 +1

## 2. 전투 및 스킬

### 2.1 기본 전투
- **데미지 공식**: `(공격력 * (100 / (100 + 방어력))) * Random(0.9 ~ 1.1)`
- **치명타**: 기본 10%, 일부 버프로 추가 확률 부여.
- **선공 판정**: 플레이어 총 속도(장비+버프 반영) vs 몬스터 속도 비교.
- **도주 확률**: `playerSpd / (playerSpd + monsterSpd)`를 사용하며 최소 5%, 최대 90%로 제한.

### 2.2 스킬/상태이상
- 플레이어 스킬은 `GAME_DATA.skills` 정의를 기준으로 소비됩니다. `bossOnly: true`인 스킬은 **몬스터 전용**이며 플레이어가 배우거나 사용할 수 없습니다.
- **묵상**: 회복 + 방어/치명 버프.
- **찬양**: 회피/속도 버프.
- **선포**: 공격형 스킬.
- 몬스터는 `skillTreeId`로 `GAME_DATA.monsterSkillTrees`의 스킬 풀을 참조합니다(드랍 테이블과 같은 ID 참조 방식). HP 구간에 따라 `lowHp` 풀로 바뀌는 보스 정의가 있습니다.
- 몬스터도 확률적으로 스킬을 사용하며, 공포·둔화 효과를 유발할 수 있습니다.
- 전투 중 효과는 턴 단위로 관리되며, UI 상태 칩으로 표시됩니다.

### 2.3 신앙 보너스
- 몬스터 요구 신앙치(`requiredFaith`)보다 플레이어 총 신앙치가 높으면 추가 피해를 얻습니다.
- 현재는 격차 기반 가산(상한 20%) 방식입니다.

## 3. 지역/진행/보상

### 3.1 지역 진행
- 기본 진행: `pishon -> gihon -> hidekel`
- 각 지역은 `bossId`, `minLevel`, `nextRegionId`를 가집니다.
- **탐사 진행도**: 일반 몬스터 전투 승리 시 `+4` (최대 100%). 진행도가 100%가 되면 탐험 시 보스 전투로 연결될 수 있으므로, 성장 후 도전하는 편이 안전합니다.
- 보스 격파 시 다음 지역 이동이 해금됩니다.

### 3.2 채도 시스템
- 일반 몬스터 처치 시 `+0.1`
- 보스 처치 시 `+10`
- 채도는 `0 ~ 100` 범위에서 누적되며 UI/CSS 필터에 반영됩니다.

### 3.3 드롭 및 상점
- 몬스터 처치 시 드롭 테이블의 각 항목을 개별 확률로 판정합니다.
- 지역별 상점(`GAME_DATA.shops`)에서 골드를 사용해 장비를 구매할 수 있습니다.

## 4. 장비/저장

### 4.1 장비 슬롯
`weapon / armor / helmet / accessory / boots / offhand` 슬롯을 사용합니다.

### 4.2 장비 아바타 UI
- 좌측 캐릭터 패널에 순례자 아바타 배경 이미지를 표시하고, 부위별 슬롯 버튼(머리/상체/허리/발/주무기/보조장비)을 오버레이합니다.
- 각 슬롯 클릭 시 장착 관리 모달이 열리며, 현재 장비 해제 또는 가방 내 같은 슬롯 아이템 장착이 가능합니다.
- 허리 슬롯은 현재 데이터 구조상 `accessory` 슬롯(벨트/장신구 공용)으로 동작합니다.

### 4.3 저장 및 백업
- 기본 저장은 계정별 `LocalStorage`를 사용합니다.
- 설정에서 백업 업로드/복원을 지원하며, 현재는 로컬 미러형 클라우드 백업 인터페이스로 동작합니다.

### 4.4 대장간(강화/분해/제작) MVP
- 하단 액션의 `🔨 대장간`에서 장비 **강화/분해/제작**을 수행할 수 있습니다.
- 강화는 `+0 ~ +5` 범위를 사용하며, 단계별 성공률/비용(골드+재료)이 적용됩니다.
- 강화 단계는 1차 구현에서 **아이템 ID 단위**로 저장되며, 동일 ID 장비에 공통 적용됩니다.
- 분해는 장비 1개를 재료/골드로 환원합니다.
- 제작은 `GAME_DATA.smithing.recipes` 기반으로 재료를 소모해 장비를 만듭니다.
- 강화 반영 스탯은 장비 합산과 함께 전투/스탯 UI에 즉시 반영됩니다.

## 5. 스킬트리 (PoE 스타일 1차)

### 5.1 개요
- 직업은 현재 **순례자(`pilgrim`) 고정**입니다.
- 레벨업으로 얻는 `skillTreePoints`를 사용해 연결된 노드를 해금합니다.
- 시작 노드에서 인접 노드만 해금 가능하며, 이미 배운 노드는 다시 선택할 수 없습니다.
- 트리에는 **수양·예언 가지·전장 측면·방패선·질주선·천상 상승·심연 저항** 등 분기가 있으며, 노드 수는 `data.js`의 `skillTrees.pilgrim`을 기준으로 한다.

### 5.2 노드 타입
- `start`: 시작 노드
- `small`: 기본 스탯 상승
- `notable`: 복합 스탯/특수 효과
- `active_unlock`: 신규 액티브 스킬 해금
- `keystone`: 전투 규칙을 크게 바꾸는 핵심 효과

### 5.3 UI
- 우측 **스킬 탭**에서 액티브/패시브를 분리해 표시합니다.
- 스킬 탭 버튼 또는 설정의 `스킬트리` 버튼으로 스킬트리 모달을 열 수 있습니다.
- 스킬트리 모달은 SVG 기반 거미줄 형태로 노드를 렌더링하며, 상태(잠김/해금 가능/해금 완료)가 색상으로 구분됩니다.
- 모달 내부에서 드래그 이동, 마우스 휠 확대/축소, 버튼 확대/축소/초기화를 지원합니다.
- 노드를 클릭하면 **선택**되고 하단 정보 패널에 상세 효과가 표시되며, **「배우기」** 버튼을 눌러야 실제 해금이 진행됩니다.
- 노드 크기는 **액티브 해금**이 가장 크고, 키스톤·시작·노터블·스몰 순으로 구분됩니다. `clusters` 계열에 따라 **색상(HSV hue)** 이 달라져 같은 길의 노드가 같은 톤을 공유합니다. 잠긴 노드는 이름 옆 **🔒** 로만 표시합니다.
- 후반에는 **하이 리스크/하이 리턴 키스톤(`잔혹한 신탁`)** 분기가 열리며, 핵심 액티브 해금 전 요구 패시브 노드 수가 증가합니다.
- 액티브 해금 라인은 `거룩한 방벽`, `심판의 강타` 외에 `수호의 기도`, `광휘 질주`, `순교자의 낙인`까지 확장되어 빌드 선택 폭을 넓혔습니다.
- 중앙부 `합일의 길`에는 다중 선행(`requiresAll`) 핵심 노드가 있어, 서로 다른 계열 노드 2~3개를 먼저 해금해야 배울 수 있습니다.
- 세계 채도(그레이스케일) 필터는 메인 플레이 영역에만 적용되며, 스킬트리 모달은 원색 UI를 유지합니다.

### 5.4 전투 반영
- 해금된 패시브는 스탯(`ATK/DEF/HP/PP/SPD/FAITH`)과 특수 효과(치명타, 회피, 피해 증폭/감소)에 실시간 합산됩니다.
- `active_unlock` 노드에서 배운 액티브 스킬은 전투 스킬 목록에 즉시 추가됩니다.
