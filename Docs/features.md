# ⚙️ Basileia 게임 시스템 상세 정의 (Features)

본 문서는 Basileia RPG의 핵심 로직과 수치 체계를 상세히 기술합니다. 개발 및 밸런싱의 기준점으로 사용됩니다.

## 1. 캐릭터 스탯 및 레벨업 시스템

### 1.1 기본 스탯 (Attributes)
플레이어는 레벨업 시 획득하는 **보너스 포인트**를 사용하여 다음 스탯을 직접 강화할 수 있습니다.

| 스탯명 | 영향력 | 비고 |
| :--- | :--- | :--- |
| **근력 (STR)** | 물리 공격력(ATK) 1.5배 증가 | 공격의 핵심 |
| **인내 (VIT)** | 최대 체력(Max HP) +15, 방어력 +0.5 | 생존의 핵심 |
| **지혜 (WIS)** | 최대 기도(Max PP) +5, 기술 위력 증가 | 스킬 효율 |
| **민첩 (AGI)** | 속도(SPD) +2, 회피율 소폭 증가 | 선공권 결정 |
| **신앙 (FAITH)** | 신앙심 데미지 보너스, 보스 지역 입장 요구치 | 핵심 성장 지표 |

### 1.2 성장 시스템
- **경험치 테이블**: `Next Exp = 100 * (1.5 ^ (CurrentLevel - 1))`
- **레벨업 보상**: 
    - 레벨업 시 **보너스 포인트 3** 지급.
    - HP/PP 전체 회복.

## 2. 전투 및 데미지 공식

### 2.1 물리 데미지 계산
- **최종 데미지** = `(공격력 * (100 / (100 + 방어력))) * Random(0.9 ~ 1.1)`
- **치명타**: 10% 확률(기본)로 발생하며, 최종 데미지의 **150%** 피해를 입힘.
- **신앙 보너스**: 플레이어 신앙심이 몬스터 요구 신앙심보다 높을 경우 최종 데미지의 **10%** 추가 피해.

### 2.2 적중 및 회피
- **적중 확률** = `(100 + 공격자 적중 - 방어자 회피) / 100` (최소 5% 보장)
- **도망 확률**: `(플레이어 속도 / (플레이어 속도 + 몬스터 속도)) * 100` (최대 90% 제한)

## 3. 인벤토리 및 장착 시스템

### 3.1 아이템 등급
- **Normal(하얀색)** - **Uncommon(초록색)** - **Rare(파란색)** - **Unique(보라색)** - **Legendary(오렌지색)** - **Mythic(황금색)**

### 3.2 장착 슬롯 (전신갑주)
플레이어는 다음의 슬롯에 아이템을 장착하여 스탯 보너스를 얻을 수 있습니다.
1. **성령의 검 (Weapon)**: 공격력 위주 증가
2. **의의 호심경 (Armor)**: 방어력, HP 위주 증가
3. **구원의 투구 (Helmet)**: 방어력, 상태이상 저항 증가
4. **진리의 허리띠 (Accessory)**: PP, 지혜 위주 증가
5. **평안의 신 (Boots)**: 속도, 회피 증가
6. **믿음의 방패 (Off-hand)**: 방어력, 막기 확률 증가

### 3.3 드랍 규칙
- 몬스터 처치 시 등급에 따라 **달란트(재화)**와 **전유물(재료)**을 확정 드랍.
- 낮은 확률로 해당 지역의 **장비 아이템** 드랍.

---

## 4. 세계의 회복 (채도 시스템)

- **채도 연동**: 현재 세계의 채도(`Saturation`)는 `0% ~ 100%` 사이의 값을 가짐.
- **회복 방식**:
    - 일반 몬스터 처치 시: `+0.1%` (무채색에서 유채색으로의 미세한 변화)
    - 네임드/보스 처치 시: `+5% ~ 10%`
- **시각적 효과**: CSS Filter의 `saturate()` 값을 `--world-saturation` 변수와 연동하여 실시간 반영.
