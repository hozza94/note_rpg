# 📖 Basileia (Note RPG) 개발 및 설정 보완 계획

본 계획서는 사용자의 Lore Book을 기반으로 웹 기반 RPG 게임을 개발하기 위한 단계별 전략과 설정 보완 방안을 담고 있습니다.

## 🎯 목표
1.  **Lore Book 완성**: 비어 있는 세계관 설정을 함께 채워나감.
2.  **텍스트 기반 프로토타입 구축**: 핵심 시스템(스탯, 전투, 아이템) 구현.
3.  **점진적 확장**: 시각 요소(이미지, 애니메이션) 및 과금 모델 도입.

## 🛠️ 기술 스택
-   **Frontend**: HTML5, Vanilla CSS (Aesthetics 우선), JavaScript (ES6+)
-   **State Management**: LocalStorage 기반 브라우저 세이브 방식
-   **Graphic/Asset**: AI 생성 이미지 (DALL-E 등) 및 CSS 애니메이션

## 📈 단계별 개발 계획

### Phase 1: 기반 다지기 (설정 및 텍스트 엔진)
*   **Lore Book 업데이트**: 지역/종족/직업 상세화.
*   **Core Engine 개발**:
    -   `GameState`: 캐릭터 정보, 인벤토리, 현재 위치 관리 시스템.
    -   `CombatManager`: `Lore Book _ Monster.md`의 데이터를 활용한 전투 로직.
    -   `UI Layout`: 텍스트 로그와 상태창이 분리된 인터페이스 구축.

### Phase 2: 시각화 및 몰입감 증대
*   **Design System**: 흑백에서 컬러로 변하는 테마 시스템 적용.
*   **Image Integration**: 지역 및 몬스터 이미지 노출.
*   **FX**: 전투 시 텍스트 흔들림, 데미지 팝업 애니메이션 추가.

### Phase 3: 콘텐츠 확장 및 밸런싱
*   **Quest System**: 시나리오 기반의 흐름 구현.
*   **Economy**: 달란트 소모처(상점, 제작) 다각화.
