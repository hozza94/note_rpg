# 🎬 Basileia Phase 3 UI & FX 강화 완료 워크스루

게임의 타격감과 감성적인 연출을 극대화하기 위한 시각 강화 작업을 완료했습니다. 이제 순례의 길에서 더욱 생생한 피드백을 경험하실 수 있습니다.

## 🛠️ 주요 구현 내용

### 1. 전투 연출 고도화 (FX)
- **데미지 팝업**: 물리 타격 시 몬스터 위로 데미지 수치가 솟구치는 효과를 추가했습니다. 몬스터가 플레이어를 공격할 때도 캐릭터창 위에 데미지가 표시됩니다.
- **시스템 통합**: 공격 로직에 데미지 수치 노출 기능이 통합되었습니다.

### 2. 치명타 연출 강화
- **치명타 시스템**: 모든 공격 시 **10% 확률**로 치명타가 발생합니다.
    - **시각적 강조**: 숫자가 더 크고 황금색으로 빛나며 역동적으로 튀어 오릅니다.
    - **화면 연출**: 치명타 시 화면이 더 크게 흔들리는 `shake-heavy` 효과와 강렬한 `crit-flash` 효과가 동시 적용됩니다.

### 3. 성경 구절 카드 연출 (예배 시스템)
- **우아한 카드 디자인**: 예배 시 로그창 출력과 동시에 화면 중앙에 반투명한 고풍스러운 카드가 나타납니다.
- **이미지 저장 기능**: **html2canvas** 라이브러리를 연동하여, 마음에 드는 성경 구절 카드를 이미지 파일(.png)로 즉시 다운로드할 수 있습니다.
- **상호작용**: 5초 후 자동 닫힘, 수동 클릭 닫힘을 모두 지원합니다.

### 4. 기타 보정
- **채도 정밀화**: 세계의 색채 지수가 소수점 첫째 자리까지 표시되도록 수정되었습니다.
