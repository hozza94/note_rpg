# 🚶 Basileia 개발기 #1: 순례의 시작

성경적 세계관을 기반으로 한 Note RPG, **Basileia**의 첫 번째 프로토타입 개발이 완료되었습니다.

## 🌟 주요 성과

### 1. 회색의 시대 (The Age of Gray) UI 구현
플레이어가 직관적으로 세계의 상태를 느낄 수 있도록 **흑백(Grayscale)** 필터가 적용된 프리미엄 UI를 구축했습니다.
- **세계의 색채 시스템**: 현재 0% 상태이며, 성장에 따라 실제 웹사이트의 채도가 돌아오는 동적 채도 시스템을 설계했습니다.
- **Glassmorphism 디자인**: 현대적이고 고급스러운 느낌을 주는 반투명 레이아웃을 적용했습니다.

### 2. 핵심 루프 프로토타입
- **탐험하기(Explore)**: 주변 유역을 탐사하며 이벤트를 조우하는 기본 로직.
- **예배하기(Worship)**: 묵상을 통해 `PP(Pray Point)`를 회복하고 성경 구절을 통해 위로와 영적 힘을 얻는 시스템.
