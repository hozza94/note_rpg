# 순례자 스킬트리 확장·레벨50 정합 (skill_tree_expand_l50_1)

## 목표

- 레벨 50 기준 누적 스킬 포인트 `(50 - 1) × 3 = 147`과, 순례자 트리 **유료 해금 노드 수**를 일치시켜 **전 노드 해금**이 가능하도록 한다.
- 트리 **양(노드·가지)**을 늘리되, 첫 링(북동남서) 거리·십일조 연장 등 **단계·거리**에 맞게 보상을 조정한다.

## 수치

| 항목 | 값 |
|------|-----|
| 순례자 노드 총수 | 148 (`pilgrim_origin` 포함) |
| 유료 해금 필요 포인트 | 147 |
| 레벨 50 시 레벨업 누적 SP | 147 (`game.js` 등 기존 규칙 유지) |

## 데이터 변경 요약 (`js/data.js`)

1. **첫 고리 외연** (`first_ring_outer`): `pilgrim_ring_{n,e,s,w}`에서 각 2단계 가지 (`out_*_1` → `out_*_2`).  
   - 1단계: 작은 보상(축 테마: 신앙/공격/방어·HP/속도).  
   - 2단계: `notable`로 합쳐 이전 3단계 분량을 한 노드에 맞춤(거리 대비 보상 밀도).

2. **십일조 연장** (`tithe_branch`): `pilgrim_tithe_2` 이후 `tithe_ep_1`~`ep_4` 4노드.  
   - 끝 노드 `ep_4`를 `keystone`으로 격상하고 PP·치명·피해량을 한 노드에 배분.

3. 초안에서 추가했던 **참회/순교/거울/생명/새벽/철척** 연장 24노드 및 외곽 4단계·십일조 8단계는 **포인트 예산 초과**로 제거. 최종 트리는 위 1+2만 반영.
