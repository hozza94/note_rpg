# 📖 Basileia - The Age of Gray

> **"죄악으로 회색빛이 된 세상을 믿음의 전신갑주를 입고 다시 컬러로 복명하며 하늘 나라에 입성하라."**

Basileia는 성경적 세계관을 바탕으로 한 웹 기반 텍스트 RPG(Note RPG)입니다. 플레이어는 '순례자'가 되어 세계의 사라진 색채를 되찾기 위한 여정을 떠납니다.

---

## 🚀 시작하기 (How to Play)

### 1. 간단히 실행하기
- 프로젝트 폴더 내의 `index.html` 파일을 크롬이나 웨일 등 웹 브라우저로 직접 엽니다.
- *주의: 일부 브라우저 환경에서는 로컬 보안 정책으로 인해 스크립트 실행이 제한될 수 있습니다.*

### 2. 로컬 서버로 실행하기 (추천)
보안 이슈 없이 모든 기능을 완벽하게 즐기려면 로컬 서버 환경에서 실행하는 것을 권장합니다.

**A. VS Code 사용자:**
- `Live Server` 확장 프로그램을 설치한 후, `index.html`에서 마우스 우클릭 > **Open with Live Server**를 선택합니다.

**B. 터미널(Node.js) 사용자:**
```bash
npx serve .
```
위 명령어를 입력한 후 출력되는 `localhost:3000` 주소로 접속합니다.

## ⚔️ 핵심 게임 시스템

### 1. 탐험 및 전투 (Explore & Battle)
- **탐험하기**: 비손 유역을 탐사하며 무작위로 몬스터와 조우합니다.
- **전투**: 속도 기반의 턴제 전투가 진행됩니다. 공격과 기술을 적절히 사용하여 몬스터를 물리치세요.
- **색의 회복**: 네임드 몬스터를 물리치거나 성장을 거듭하면 세계의 채도(Saturation)가 점진적으로 회복됩니다.

### 2. 예배 및 묵상 (Worship & Meditation)
- **예배하기**: 소모된 `PP`를 100% 회복하고 성경 구절을 통해 영적인 위로를 얻습니다.
- **축복**: 예배를 통해 일시적이거나 영구적인 스탯 보너스를 획득할 수 있습니다.

### 3. 저장 및 지속성 (Storage)
- **자동 저장**: 시스템은 모든 성장 데이터와 인벤토리를 브라우저의 `LocalStorage`에 실시간으로 저장합니다.
- **추상화 엔진**: 현재는 로컬 저장소를 쓰지만, 추후 Firebase 등 백엔드 서비스로 이관이 용이하도록 설계되었습니다.

## 📂 프로젝트 구조
- `index.html`: 게임의 메인 레이아웃 및 UI
- `style.css`: 흑백/컬러 가변 테마 및 고급 UI 디자인
- `game.js`: 게임 엔진 및 전투 로직
- `js/data.js`: 몬스터, 아이템, 스킬 데이터베이스
- `js/storage.js`: 데이터 보존 및 저장소 관리 레이어
- `Lore Book/`: 세계관 설정 및 데이터 원본 문서
